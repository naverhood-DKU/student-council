## 서비스에서 쓰는 방법

- 규정 등록 화면(`규정 → 규정 올리기`)에서 위 규정을 올려 "제n조" 단위로 나눈 뒤, 사람이 원문과 대조해 검수하고 확정하면 지출 절차 안내의 근거가 됩니다.
- 확정하지 않은 규정은 검색되지 않습니다. 조항 원문은 검수된 값 그대로 화면에 나옵니다.
- `scripts/eval/expense` 의 평가 사례는 가상 재정 세칙(`rules-sample.txt`) 기준이며, 이 폴더의 실제 규정으로 평가하려면 규정 담당자가 사례와 정답 조항을 새로 검수해야 합니다.
